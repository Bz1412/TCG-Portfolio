# ตัวสแกนการ์ด v4 — ปรับการอ่านชื่อและรหัส

รุ่นนี้เน้นหน้ากล้องที่เรียบง่าย แบ่งเป็น 2 ขั้นตอน: สแกน และ ตรวจรายการ ใช้บน GitHub Pages กับคิว TcgTasks/Google Sheets เดิมได้ ไม่มี API key หรือค่าบริการ OCR ต่อรูป

## อัปเดตจาก v2/v3 เป็น v4

แทนที่เฉพาะ card-scanner.js แล้วเปลี่ยนแท็กสคริปต์เดิมใน index.html เป็น:

```html
<script src="./card-scanner.js?v=4"></script>
```

เก็บ CSS, card-vision.js, card-catalog.json และคิวงานเดิมไว้ ใช้ตัวเลือกภาษาจีนใน index.html จากรุ่นก่อนต่อได้

สิ่งที่เปลี่ยน:
- แยกตัวอ่านรหัสเป็นอังกฤษ และจำกัดอักขระของรหัส แยกจากตัวอ่านชื่อหลายภาษา
- อ่านส่วนล่างสองแบบ (สีเดิมและสีเทาปรับคอนทราสต์) หากยังไม่ได้รหัส จะลองพื้นที่กว้างขึ้นอีกครั้ง
- เติมรหัสเมื่อมีผลตรงกันอย่างน้อยสองครั้งและไม่มีผลที่ขัดกัน ไม่แทน O/0 หรือ G/6 แบบเดาสุ่ม
- อ่านแถบชื่อสองขนาด ตรวจกลุ่มอักษรตามภาษาที่เลือก และใช้ผลตรงกันสองครั้งพร้อมเกณฑ์คะแนน OCR ขั้นต่ำ คะแนนนี้ไม่ใช่เปอร์เซ็นต์ความถูกต้อง
- แก้การตัดสระ/วรรณยุกต์ไทยท้ายชื่อ เปรียบเทียบบรรทัดที่ผ่านตัวกรองจากทั้งสองรอบ แทนเลือกบรรทัดยาวที่สุด
- เมื่อผลไม่ผ่านเกณฑ์ ช่องจะว่างเพื่อให้ตรวจเอง เก็บข้อความดิบจากแต่ละครั้งไว้ในรายละเอียด ไม่สามารถกรองชื่อผิดที่ดูเหมือนภาษาปกติได้ทั้งหมด
- การอ่านซ้ำใช้เวลามากกว่ารุ่นก่อน ชื่อที่แก้เองจะไม่ถูกชื่อจากแค็ตตาล็อกทับ

ก่อนสแกนเลือกภาษาให้ตรงกับการ์ด ถ้าทราบ Set เช่น MA6 T ให้กรอกในช่องรหัส Set เพื่อไม่ต้องอ่านส่วนนี้จากภาพ หากชื่อมาจาก OCR เดิม กดอ่านใหม่จะประเมินชื่อใหม่ ส่วนรหัสที่มีค่าอยู่จะคงเดิม: ล้างรหัสที่ผิดก่อนกดอ่านใหม่ ชื่อที่เคยแก้เองต้องล้างก่อนหากต้องการให้ OCR เติมใหม่

หากยังผิด ส่งภาพเต็มใบที่ใช้สแกนและข้อความที่อ่านได้เพื่อปรับตามการ์ดจริง รุ่นนี้ยังไม่มีข้อมูลวัดความแม่นยำกับการ์ดของคุณ

## ถ้าใช้ v2 อยู่แล้ว: อัปเดตภาษา

1. แทนที่เฉพาะ card-scanner.js แล้วเปลี่ยนแท็กเดิมเป็น `<script src="./card-scanner.js?v=4"></script>` หลัง background-tasks.js
2. ใน index.html ค้นหา `<select id="form-lang"` และ `<select id="filter-lang"` เพิ่มสอง option ต่อไปนี้ภายใน select ทั้งสองจุด โดยเก็บตัวเลือกเดิมไว้:

```html
<option value="CN">จีนตัวย่อ</option>
<option value="TW">จีนตัวเต็ม</option>
```

3. เก็บ CSS, card-vision.js, คิวงาน และ card-catalog.json เดิมไว้ ไม่ต้องเปลี่ยน Apps Script หรือเพิ่มคอลัมน์ใน Sheets ใช้คอลัมน์ language เดิม (CN/TW เป็นค่าที่แอปนี้ใช้แยกจีนสองรูปแบบ)
4. เลือกภาษาใน “ตัวเลือกการสแกน” ก่อนถ่าย หากเป็นฉบับร่างเก่า ให้เปลี่ยนภาษาใน “ตรวจรายการ” แล้วกด “อ่านใหม่” ชื่อที่แก้เองจะยังคงเดิม หากต้องการให้ OCR เติมใหม่ให้ล้างช่องชื่อก่อน

ระบบไม่ได้เลือกภาษาอัตโนมัติ โหลดเฉพาะภาษาที่เลือกและอังกฤษเพื่อช่วยอ่านรหัส ไม่โหลดทุกภาษาพร้อมกัน การดาวน์โหลดโมเดลครั้งแรกต้องใช้อินเทอร์เน็ต และทุกภาษายังต้องตรวจชื่อก่อนบันทึก

## ถ้าติดตั้งตัวสแกนรุ่นแรกแล้ว: เปลี่ยนเพียง 3 ไฟล์

1. แทนที่ card-scanner.js ทั้งไฟล์ด้วยไฟล์ในชุดนี้
2. แทนที่ card-scanner.css ทั้งไฟล์ด้วยไฟล์ในชุดนี้
3. เพิ่มไฟล์ใหม่ card-vision.js ไว้ข้าง index.html และ card-scanner.js

**เก็บ card-catalog.json ของคุณไว้ อย่านำไฟล์ [] ในชุดนี้ไปทับข้อมูลอ้างอิงที่กรอกไว้แล้ว** ไม่ต้องเพิ่มฟังก์ชันคิวซ้ำ ไม่ต้องเปลี่ยน API_URL และไม่ต้องแก้ Apps Script หรือ Sheets สำหรับการอัปเดตนี้

ใน index.html เปลี่ยนแท็ก CSS เดิมเป็น:

```html
<link rel="stylesheet" href="./card-scanner.css?v=2">
```

เปลี่ยนแท็ก JavaScript ของตัวสแกนเดิมเป็น:

```html
<script src="./card-scanner.js?v=4"></script>
```

เก็บแท็กนี้ไว้หลัง background-tasks.js เช่น:

```html
<script src="./background-tasks.js?v=4"></script>
<script src="./card-scanner.js?v=4"></script>
```

ไม่ต้องเพิ่มแท็ก script ของ card-vision.js เพราะตัวสแกนโหลดให้เองตอนเปิดกล้อง ปุ่ม CardScanner.open() เดิมใช้ต่อได้

Commit ไฟล์ รอ GitHub Pages อัปเดต แล้วรีเฟรชเว็บ หากเบราว์เซอร์ยังใช้ JavaScript เก่า ให้เพิ่มเลข v ในแท็ก JavaScript อีกครั้ง

## วิธีใช้งาน

1. เข้าสู่ระบบผู้ดูแล แล้วกดปุ่มสแกนการ์ด
2. ใน “ตัวเลือกการสแกน” เลือกภาษาบนการ์ด: ไทย / ญี่ปุ่น / อังกฤษ / จีนตัวย่อ / จีนตัวเต็ม (ภาษาอื่นอ่านร่วมกับอังกฤษสำหรับรหัส) ถ้ารู้รหัส Set ให้กรอกไว้ช่วยอ่าน
3. กด “เปิดกล้อง” แล้วอนุญาตกล้อง
4. วางหน้าการ์ดตั้งตรงบนพื้นเรียบที่สีตัดกับการ์ด ให้เห็นครบทั้งสี่มุม กรอบสีเหลืองแสดงขอบที่ตรวจพบ
5. ถือให้นิ่งประมาณ 1.2 วินาที ระบบจะจับภาพเมื่อขอบและภาพนิ่ง แล้วอ่านชื่อกับเลขการ์ด
6. ดูภาพเต็มใบในช่อง “ใบล่าสุด” แตะรูปเพื่อขยาย
7. เปลี่ยนการ์ดแล้วกด “ใบถัดไป” ระบบจะเริ่มจับภาพใบใหม่ การพักหลังจับแต่ละใบช่วยไม่ให้ภาพเดิมถูกเพิ่มซ้ำ
8. ไป “ตรวจรายการ” กดรายการเพื่อแก้ข้อมูล สภาพ ราคา ต้นทุน และจำนวน จากนั้นติ๊กตรวจแล้ว
9. กดบันทึก ระบบส่งเฉพาะรายการที่ยืนยันผ่านคิวเดิม รูปจะจับคู่กับงานการ์ดของใบนั้น

การสแกนเก็บเป็นฉบับร่างก่อน ยังไม่เขียนลง Sheets จนกว่าจะยืนยัน รูป/ฉบับร่างรุ่นเดิมเปิดต่อได้เพราะใช้พื้นที่เก็บเดิมในเบราว์เซอร์

## การจับภาพเต็มใบ

- ตรวจขอบรูปสี่เหลี่ยมที่มีสัดส่วนใกล้การ์ด แล้วใช้สี่มุมปรับภาพเอียงให้ตรง พร้อมเผื่อขอบเล็กน้อย
- วิธีนี้ตรวจรูปทรง ไม่ใช่โมเดลที่ยืนยันว่าเป็นการ์ดโปเกมอนเสมอไป ซองสะท้อนแสง พื้นหลังลายมาก หรือมือบังมุมทำให้จับขอบผิดได้
- หากจับขอบไม่ได้ ใช้ปุ่มกลมถ่ายเองได้ จะครอปตามกรอบจัดการ์ด และแสดงว่า “ถ่ายตามกรอบ”
- เก็บภาพก่อนครอปไว้ด้วย ที่ “รูปภาพและข้อมูลเพิ่มเติม” เลือก “ใช้ภาพก่อนครอป” ได้ หากกรอบตัดขอบการ์ดผิด
- ภาพที่หมุนผิดด้านสามารถกด “หมุนภาพ” แล้ว “อ่านใหม่”
- กล้องถ่ายทีละใบ ส่วนเลือกรูปหลายไฟล์ยังใช้ได้ โดยแต่ละรูปควรมีการ์ดหนึ่งใบที่ตั้งตรงและเต็มภาพ รูปที่เลือกจะใช้ทั้งภาพ ไม่ได้ตรวจขอบอัตโนมัติแบบกล้อง

## การอ่านชื่อและรหัส

- Tesseract.js อ่านแถบชื่อด้านบนจากภาพจริง โดยโหลดโมเดลตามภาษาที่เลือก
- อ่านรหัส Set/เลขการ์ดจากส่วนล่าง (เลือกอ่านทั้งหน้าได้สำหรับตำแหน่งพิเศษ)
- ถ้ารหัส+เลข+ภาษาตรงกับข้อมูลใน allCards หรือ card-catalog.json จะใช้ข้อมูลอ้างอิงเติมชื่อ Set และความหายาก
- ช่องใบล่าสุดบอกว่าชื่อมาจากภาพหรือข้อมูลอ้างอิง ชื่อจาก OCR ยังต้องตรวจตัวสะกด โดยเฉพาะชื่อภาษาไทย ตัวเล็ก และการ์ดฟอยล์
- การอ่านใหม่จะเติมรหัสเฉพาะช่องที่ว่าง เพื่อรักษาค่าที่แก้เอง ถ้าต้องการอ่านรหัสที่ผิดใหม่ ให้ล้างช่องนั้นก่อน ส่วนชื่อที่แก้ด้วยมือจะไม่ถูก OCR ทับ
- รุ่นนี้ยังให้กรอกราคา/สภาพเอง และเพิ่มเป็นรายการใหม่ พร้อมเตือนรายการที่อาจซ้ำ ไม่รวมจำนวนเข้ารหัสการ์ดเดิมอัตโนมัติ
- การ์ดเกรดที่ต้องกรอก Cert ใช้ฟอร์มเดิม ตัวสแกนนี้รองรับ NM/LP/MP/HP

## ความเร็วและอินเทอร์เน็ต

ครั้งแรกต้องดาวน์โหลดตัวจับขอบและโมเดลภาษา จึงอาจช้ากว่าครั้งถัดไป ตัวจับขอบและ OCR ประมวลผลในเครื่อง รูปส่งไป Drive/Sheets เฉพาะหลังยืนยันเข้าคิวเท่านั้น

หากโหลดตัวจับขอบไม่ได้ ยังถ่ายเองได้ หาก OCR อ่านไม่สำเร็จ รูปยังเก็บเป็นฉบับร่างและกรอกเองได้ การปิดเว็บ/พักแอปอาจหยุดงานคิว แล้วทำต่อเมื่อเปิดเว็บและเข้าสู่ระบบอีกครั้ง

## หากยังไม่ได้ติดตั้งตัวสแกนรุ่นแรก

1. วาง card-scanner.js, card-scanner.css, card-vision.js และ card-catalog.json ไว้ข้าง index.html
2. เปิด queue-scanner-addon.js คัดลอกฟังก์ชัน enqueueScannedCards ทั้งฟังก์ชันไปวางใน background-tasks.js ภายใน IIFE ของ TcgTasks ก่อนบรรทัด return ใกล้ท้ายไฟล์
3. เปลี่ยนบรรทัดเริ่มต้น return จาก:

```js
return {start, enqueueMutation, chooseImage, clearImage, copy,
```

เป็น:

```js
return {start, enqueueMutation, enqueueScannedCards, chooseImage, clearImage, copy,
```

เก็บ toggle/retry/cancel และเนื้อหาถัดจากบรรทัดนี้ไว้ทั้งหมด ไม่วางฟังก์ชันหลัง TcgTasks.start() และไม่โหลด queue-scanner-addon.js ด้วยแท็ก script

4. เพิ่มแท็ก CSS ก่อน </head> และเพิ่มแท็ก card-scanner.js หลัง background-tasks.js ตามตัวอย่างด้านบน สคริปต์หลักของเว็บต้องอยู่ก่อนทั้งสองไฟล์ และแต่ละไฟล์โหลดครั้งเดียว
5. ก่อนบรรทัด `<form id="card-form" ...>` ใน index.html เพิ่ม:

```html
<button type="button" onclick="CardScanner.open()"
        class="w-full py-3 rounded-xl bg-emerald-600 text-white font-bold text-sm">
    📷 สแกนการ์ดหลายใบ
</button>
```

6. ใช้หลังบ้านรุ่นคิวเดิมที่รองรับ backgroundSchemaVersion:1, requestId, mutationStatus และ responseMode:'ack' หากแถบงานขอให้ Deploy รุ่นคิวงาน ต้อง Deploy โค้ดคิวงานเดิมก่อน

card-catalog.example.json เป็นเพียงตัวอย่างข้อมูลอ้างอิง หากไม่มีข้อมูลอ้างอิง สามารถเริ่มจาก card-catalog.json ที่เป็น [] แล้วตรวจชื่อจาก OCR และกรอกช่องที่เหลือเองได้

## สิ่งที่ตรวจแล้ว

- v4 ผ่านการทดสอบ 19 กรณี รวมการกันผลขัดแย้ง การรักษาอักษรประกอบไทย และชื่อที่แก้เอง
- v4 ทดสอบตัว OCR จริงกับภาพจำลอง: อ่าน Nidorina และ 143/130 ได้ แต่ MA6 T ยังอ่านเป็น MAG T จึงเว้นรหัสไว้ ชื่อไทย นิโดรินา ยังอ่านเป็น นิโครนา ทั้งสองรอบ แสดงว่าการอ่านซ้ำไม่ยืนยันความถูกต้อง และยังต้องทดสอบกับภาพการ์ดจริงของผู้ใช้

- v3 ตรวจการเลือกโมเดล TH/JP/EN/CN/TW การแยกชื่อจีน การเก็บ Unicode ในฉบับร่างและส่งเข้าคิว ยังไม่ได้วัดความแม่นยำ OCR กับการ์ดจีนจริง

- ตรวจ syntax และทดสอบฉบับร่าง/คิว/การตรวจข้อมูล รวมถึงการกันจับซ้ำ การจับขอบนิ่ง และตัวโหลด OpenCV
- เปิดหน้าจอใน Chromium จำลองจอเดสก์ท็อปและมือถือ ตรวจว่าหน้าไม่ล้นแนวนอน
- ทดสอบ OpenCV และ Tesseract ตัวจริงกับภาพการ์ดจำลองในกล้องเสมือน: จับอัตโนมัติ ครอปเต็มใบ อ่านชื่อ Nidorina และเลข 143/130 ได้ และไม่เพิ่มรายการซ้ำเมื่อภาพค้าง
- โมเดลภาษาไทยโหลดและอ่านข้อความได้ แต่ยังพบการสะกดชื่อคลาดเคลื่อนในภาพจำลอง จึงต้องตรวจชื่อก่อนบันทึก
- การทดสอบภาพจำลองไม่ใช่การวัดความแม่นยำกับการ์ดจริงทุกแบบ ยังไม่ได้ทดลองกับกล้องมือถือของคุณ และไม่ได้เขียนลงฐานข้อมูลจริง ควรเริ่มด้วย 1–2 ใบแล้วตรวจภาพ/ชื่อ/จำนวนก่อน
